# 상태: 부분 통합 소스 제공 — 운영 미승인

**완료:** 기존 Master 단일 React 앱에 계획 메뉴를 삽입하는 TSX 소스, Python `planning.*` 요청 서비스, Phase7 시간표/이동반 순수 엔진 사용, 독립된 계획 저장소 시범 구현, 로컬 계산/검증 테스트.

**미완료:** 브라우저 배포용 React dist 재빌드, 실운영 로그인·Google Sheets 저장 확인, 학생 수강신청 포털, 완전한 UI 폼 동등성, CP-SAT 실설치 E2E, 데이터 운영 전환, 전체 회귀 테스트.

**안전 조건:** 기존 Master의 시험감독/교무행정/수업운영 코어를 교체하지 않는다. 새 계획에서 확정한 버전은 신규 초안만 변경하고 기존 수업운영 시간표에는 전송하지 않는다.

**사용 방법:** React 프로덕션 빌드와 모든 테스트가 완료되기 전에는 이 ZIP을 운영 GitHub 배포 브랜치에 업로드하지 말 것.
